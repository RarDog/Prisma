## О проекте

**Prisma** — высокопроизводительное мультимедийное кроссплатформенное приложение, спроектированное на Flutter с акцентом на приватность, минимальное потребление ресурсов и плавность интерфейса. Приложение объединяет популярные booru-имиджборды, архивы авторов, каталоги манги и новелл в единую адаптивную оболочку Material 3 для мобильных и десктопных устройств.

Архитектура Prisma оптимизирована для частоты обновления 60/120 FPS и предсказуемого управления памятью: многостраничные галереи и видео высокого разрешения отображаются без микрофризов и утечек ОЗУ.

## ⚡ Ключевые преимущества

* **Упреждающая предзагрузка ленты**: Интеллектуальный механизм предварительной подгрузки последующих страниц обеспечивает бесшовный бесконечный скролл без ожидания.
* **Аппаратный видео-конвейер**: Интегрированный плеер на базе `media_kit` (libmpv) с низкой задержкой до первого кадра (TTFF) и поддержкой WebM/MP4.
* **Масштабная экосистема**: Поддержка свыше 15 имиджборд, переводческих хабов манги, библиотек новелл и сетей авторов.
* **Детерминированное скользящее окно памяти**: Строгая изоляция карусели ($\pm 1$ страница) с принудительной выгрузкой неактивных растровых декодеров.
* **Сетевая телеметрия в реальном времени**: Точный замер пинга (RTT) через монотонные таймеры `Stopwatch`, потоковая диагностика и защита от ложных статусов.
* **Адаптивный стеклянный интерфейс**: Выбор расположения навигационной панели на ПК (слева / справа / снизу), глубокий черный AMOLED и дизайн Liquid Glass.

## 🚀 Основные возможности

### 📱 Просмотр ленты и медиа
* **Адаптивные раскладки**: Бесконечная masonry-сетка (в стиле Pinterest), квадратные карточки 1:1 и плотный список.
* **Профили качества контента**: Настройка разрешения под условия сети — *Авто*, *Экономия трафика / Превью*, *Sample / Сбалансированное* или оригинальный файл без сжатия.
* **Детальный просмотрщик**: Многоточечный pinch-to-zoom, инерционные жесты панорамирования, переключение вариантов медиа и отображение текстовых заметок с переводом (Danbooru notes).
* **Сеты вариаций и манга**: Индикация многостраничных работ в ленте и компактный нижний переключатель страниц со стрелками в деталях поста.

### 📚 Центр манги и ранобэ
* **Глобальные каталоги**: Прямой стриминг и чтение тайтлов с **MangaDex**, **MangaLib** и **RanobeLib**.
* **Специализированные движки чтения**:
  * **Режим Webtoon**: Плавный вертикальный бесконечный свиток с аппаратным декодированием страниц.
  * **Читалка манги**: Традиционные направления чтения справа налево (RTL) и слева направо (LTR) с настройкой полей.
  * **Типографика ранобэ**: Движок верстки текста с выбором шрифтов, размера кегля, межстрочного интервала и комфортных тем для глаз.
* **Управление прогрессом чтения**: Автоматическое сохранение прочитанных глав, отметки новинок и категоризация библиотеки (*Читаю*, *В планах*, *Прочитано*, *Отложено*, *Брошено*).

### 🔍 Поиск и интеллектуальная фильтрация
* **Моментальный автокомплит тегов**: Подсказки с субмиллисекундным откликом из базы миллионов тегов.
* **Сложный синтаксис запросов**: Мультитеговый поиск, логическое исключение (`-tag`), оператор `and` и мгновенное переключение источников без потери параметров фильтрации.
* **Трехуровневая защита контента**: Гибкий черный и белый списки тегов, умное авторазмытие деликатных изображений и быстрое переключение между безопасным (Safe) и открытым режимами.
* **Центр авторов**: Прямой переход к портфолио художников и каталогизация авторских галерей.

### 🛡️ Оптимизация памяти и диагностика
* **Умный сборщик мусора (Smart GC & Watchdog)**: Перехват системных сигналов нехватки памяти с очисткой растровых поверхностей до вмешательства OOM-киллера ОС.
* **Скользящее окно в памяти**: Дерево виджетов удерживает только активный и соседние слайды ($\pm 1$), выгружая удалённые ресурсы из ОЗУ.
* **Плавающий HUD мониторинга**: Инженерная диагностика в реальном времени с выводом потребления RAM (RSS и Peak), объема кэша, FPS движка и сетевого трафика.

## 🏗️ Архитектура и стек технологий

Проект базируется на принципах Clean Architecture с четким разделением слоёв:

```
┌────────────────────────────────────────────────────────┐
│               Слой представления (UI)                  │
│    Material 3 • Адаптивные брейкпоинты • Liquid Glass  │
└───────────────────────────▲────────────────────────────┘
                            │ Riverpod State Management
┌───────────────────────────┴────────────────────────────┐
│                    Домен и логика                      │
│   Контроллеры ленты • Стейт поиска • Движок префетча   │
└───────────────────────────▲────────────────────────────┘
                            │ Контракты репозиториев
┌───────────────────────────┴────────────────────────────┐
│                Данные, хранилище и ядро                │
│  Isar DB (NoSQL) • media_kit (libmpv) • Dio HTTP Pool │
└───────────────────────────▲────────────────────────────┘
                            │ Сетевые адаптеры
┌────────────────────────────────────────────────────────┐
│     Внешние источники (REST • DAPI • Парсеры • Auth)   │
└────────────────────────────────────────────────────────┘
```

* **Фреймворк**: [Flutter](https://flutter.dev) (Dart 3.3+)
* **Управление состоянием**: [Riverpod 2.6](https://riverpod.dev)
* **Локальная СУБД**: [Isar Database](https://isar.dev) (высокопроизводительная NoSQL БД)
* **Декодирование медиа**: [media_kit](https://github.com/media-kit/media-kit) (C-биндинги libmpv)
* **Сетевой уровень**: [Dio](https://pub.dev/packages/dio) с пулом keep-alive соединений

## 🛠️ Сборка из исходников

### Требования
* [Flutter SDK](https://flutter.dev/docs/get-started/install) (`>= 3.24.0`)
* [Dart SDK](https://dart.dev/get-dart)
* JDK 17 и Android Command Line Tools (для сборки под Android)
* Системные пакеты для Linux:
  ```bash
  sudo apt-get install -y clang cmake ninja-build pkg-config libgtk-3-dev libmpv-dev liblzma-dev
  ```

### Команды сборки
```bash
# 1. Клонирование репозитория
git clone https://github.com/RarDog/Prisma.git
cd Prisma

# 2. Установка зависимостей
flutter pub get

# 3. Запуск в режиме разработки
flutter run

# 4. Сборка раздельных APK для Android
flutter build apk --release --split-per-abi

# 5. Сборка релизной версии под Linux
flutter build linux --release
```
